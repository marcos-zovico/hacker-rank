# Java Inheritance I

**Problem:** [Java Inheritance I](https://www.hackerrank.com/challenges/java-inheritance-1/problem)

## Summary

Create a Bird class that extends Animal. Override the fly() method to print "Bird is flying". The walk and sing methods may also be overridden or inherited as required.

## Approach

Define class Bird extends Animal. Override fly() to print the required message.

## Solution Details

- `class Bird extends Animal { void fly() { System.out.println("Bird is flying"); } }` (and any walk/sing as per problem).

## Time and Space Complexity

- **Time:** O(1)
- **Space:** O(1)

## Example

| Input | Output |
|-------|--------|
| (none) | Bird is flying |
