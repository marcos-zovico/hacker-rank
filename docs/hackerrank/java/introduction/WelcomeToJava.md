# Welcome to Java

**Problem:** [Welcome to Java](https://www.hackerrank.com/challenges/welcome-to-java/problem)

## Summary

Print two lines: "Hello, World." and "Hello, Java."

## Approach

Use `System.out.println` for each line.

## Solution Details

```java
System.out.println("Hello, World.");
System.out.println("Hello, Java.");
```

## Time and Space Complexity

- **Time:** O(1)
- **Space:** O(1)

## Example

| Input | Output |
|-------|--------|
| (none) | Hello, World.<br>Hello, Java. |
